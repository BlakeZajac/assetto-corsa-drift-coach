# Drift Coach

Open Drift Coach from the in-game apps sidebar. Enter a recording name, press Record, drive a clean run, then press Stop and save. Runs shorter than one second are discarded. Select Use beside a saved run, then drive through the white start circle to release the ghost. Reset ghost starts another attempt. Painted line and Ghost car can be toggled separately. Green paint means throttle, red brake, purple handbrake, and blue circles clutch kicks. Settings includes record/reset button bindings, line opacity and start radius. Runs are saved in Documents/Assetto Corsa/drift-coach, grouped by track, layout and car. The updated Drift HUD in the source workspace adds recorded pedal markers; it is optional and distributed separately. The ghost body does not animate wheel steering.

## Install

Requires Assetto Corsa, Content Manager and Custom Shaders Patch with Lua apps and scripted chase cameras. Installed locally against CSP 0.3.0-preview649; in-game testing remains pending. Pure is optional.

1. Close the driving session.
2. Copy the top-level apps/ and/or extension/ folders present here into your Assetto Corsa installation, merging folders.
3. For the camera, open Content Manager > Settings > Custom Shaders Patch > Chase Camera, enable scripted cameras and select Drift Coach. Start a session and choose a chase view. Tune its options on the same settings page.

## Try it

Start at Brooklyn Park. Use the same car, time, weather and graphics settings when comparing runs. Restart the session after installing. Camera placement and ghost rendering still need checking in-game.

## Remove

Select another chase camera, close the session and delete only the mod folders copied from this project. Drift Coach recordings in Documents are kept separately.
